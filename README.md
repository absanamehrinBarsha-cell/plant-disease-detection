# Plant Disease Detection System

AI-powered plant disease identification system.

## AI Components

- MobileNetV2 - Vision Agent
- TF-IDF - Text Feature Extraction
- SVM - Text Classification
- Calibrated SVM - Confidence Estimation
- Fusion Agent - Final Decision
- Gradio - Web Interface

## Classification

16 plant disease classes are supported.

## Deployment

This package is prepared for deployment on Render.

Build command:

pip install -r requirements.txt

Start command:

bash start.sh

## Project Integrity

The existing trained models were copied without retraining.
Notebook 10 was not modified.
